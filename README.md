# VibeCast Studio — веб-аудиоплеер

Веб-приложение для прослушивания музыки: каталог треков с поиском и пагинацией, избранное, профиль пользователя и полноценный плеер с управлением воспроизведением.

## Возможности

### Каталог треков
- Список треков с обложкой-заглушкой, названием, исполнителем, альбомом и датой добавления («N дней назад»).
- Пагинация: на десктопе — постраничная навигация (10 треков на страницу), на мобильных — бесконечная лента (подгрузка по 5 треков через IntersectionObserver).
- Поиск по названию и исполнителю («Что будем искать?»).
- Подсветка текущего трека в списке.

### Избранное
- Добавление/удаление сердечком прямо в списке и через меню «…» строки.
- Отдельная вкладка «Избранное» с тем же списком.
- Состояние синхронизируется с сервером и между списком и плеером: сердечко в плеере всегда отражает актуальное состояние.

### Плеер
- Play/pause, предыдущий/следующий трек, перемотка на ±10 секунд.
- Прогресс-бар с возможностью клика для перехода к нужной секунде.
- Режимы повтора: выключен → повтор всех → повтор одного трека.
- Shuffle (перемешивание).
- Регулировка громкости с иконкой mute при нуле.
- Мини-кнопка play рядом с информацией о треке для мобильных (`player__btn--play-mini`, видна только на узких экранах).
- Клавиатурные шорткаты: `Space` — play/pause, `←`/`→` — перемотка на ±10 секунд (не срабатывают в полях ввода).

### Профиль
- Регистрация и вход (токен хранится в localStorage, при 401 — автоматический выход).
- Редактирование профиля: имя, email, описание.
- Аватар: загрузка фото с обрезкой до 256×256 и сжатием в JPEG (canvas → dataURL).

## Технологии

- **TypeScript** (strict, без `any`)
- **Redom** — построение DOM
- **SCSS + БЭМ** (общие переменные в `_variables.scss`, палитра: фиолетовый `#7C5CFC`)
- **Webpack 5** — сборка фронтенда
- **Express** — бэкенд (Node.js)

## Запуск

### Бэкенд (порт 8000)

```bash
cd express-backend
npm install
npm start
```

### Фронтенд (порт 3000)

```bash
npm install
npm run dev
```

## API

Базовый префикс: `/api`.

| Метод | Эндпоинт | Описание |
|---|---|---|
| GET | `/api/tracks` | Каталог треков |
| GET | `/api/favorites` | Избранное текущего пользователя |
| POST | `/api/favorites/:id` | Добавить в избранное |
| DELETE | `/api/favorites/:id` | Убрать из избранного |
| GET | `/api/profile` | Профиль текущего пользователя |
| PUT | `/api/profile` | Частичное обновление профиля (`undefined` — не трогать, `null` — очистить) |
| POST | `/api/register` | Регистрация |
| POST | `/api/login` | Вход |


## Особенности воспроизведения

Источники аудио пробуются по цепочке, с предварительной `HEAD`-проверкой (чтобы не терять пользовательское разрешение на звук между неудачными попытками):

1. Файлы с сервера (если есть для трека).
2. Внешний источник SoundHelix (Song-1…17) — играется без CORS-проверки.
3. Сгенерированная WAV-заглушка (детерминированная по id трека и длительности) — гарантированный fallback.

## Примечания

- Данные бэкенда хранятся в памяти и сбрасываются при перезапуске сервера.
- Ошибки операций с избранным сейчас логируются в консоль (тосты не подключены).
